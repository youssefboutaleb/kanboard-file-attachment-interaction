# Project Roadmap

This roadmap outlines the planned evolution of `kanboard-file-interaction-core`.

---

## Milestone 1: Safe Read-Only Text Preview (Current)
- Safe preview for `.txt` files
- Formatted preview for `.json` files
- Raw plain text preview for `.md` files
- Hardened output escaping & size validation
- Unit tests & automated CI pipeline

## Milestone 2: Rich Document Viewers & CSV Grid
- Read-only CSV grid rendering with column sorting
- Safe HTML-sanitized Markdown rendering
- PDF embedded read-only previewer

## Milestone 3: Safe In-App Editing & Versioning
- Plain text & JSON live editor with line numbers
- Pre-save validation & syntax checking
- Kanboard attachment version history tracking

## Milestone 4: Advanced Formats & Collaborative Editing
- Excel spreadsheet preview/edit view
- Integration options for OnlyOffice / Collabora
- Automated workflow triggers on file modification
